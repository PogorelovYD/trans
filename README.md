# Cicada RU — Windows x64

Русская сборка [Cicada](https://github.com/wquguru/cicada) для Windows 10/11 x64.

## Что находится в этом репозитории

Это overlay-репозиторий локализации и сборки, а не полная копия исходников Cicada. Он хранит русские переводы, скрипт применения изменений и GitHub Actions workflow. Исходный проект загружается из upstream на закреплённом коммите:

`be9785d562dfcfd22e3d1753a991400c5781f330`

## Сборка

1. Откройте вкладку **Actions**.
2. Выберите **Cicada RU Windows x64**.
3. Нажмите **Run workflow**.
4. После успешного завершения скачайте artifact **Cicada-RU-Windows-x64**.

Файл `Cicada-RU-Windows-x64.exe` — самораспаковывающийся установщик Cicada, как и в оригинальном проекте.

## Локализация

- `overlay/ru_windows.json` — русские строки Windows-интерфейса.
- `overlay/apply_ru.py` — создаёт русские таблицы локализации, добавляет Russian / Русский в настройки и включает культуру `ru-RU`.
- Не переведённые строки пока остаются на английском, чтобы интерфейс не показывал китайский исходный текст.

## Обновление upstream

Чтобы обновить базу Cicada, измените закреплённый upstream commit в workflow, проверьте совместимость overlay и выполните сборку заново.

## Важно

Сборка не подписана сертификатом издателя Windows. При первом запуске Windows SmartScreen может показать предупреждение. Используйте только сборки из этого репозитория и проверяйте исходный код.
