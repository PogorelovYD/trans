# Cicada RU — Windows x64

Русская сборка [Cicada](https://github.com/wquguru/cicada) для Windows 10/11 x64.

## Установка поверх оригинальной Cicada

Cicada RU собирается с версией `1.10.2`, чтобы установщик распознал её как обновление оригинальной версии `1.10.1`.

**Старую Cicada удалять не нужно.** Запустите `Cicada-RU-Windows-x64.exe` и подтвердите обновление. Приложение заменит файл в `%LOCALAPPDATA%\\Programs\\Cicada`, а пользовательские данные останутся в `%APPDATA%\\Cicada`:

- записи встреч и аудио;
- настройки;
- сохранённый API-ключ Ling.

Не используйте пункт «Удалить» и не удаляйте папку `%APPDATA%\\Cicada`.

Если на компьютере установлена версия новее `1.10.2`, установщик не заменит её автоматически.

## Сборка

1. Откройте вкладку **Actions**.
2. Выберите **Cicada RU Windows x64**.
3. Нажмите **Run workflow**.
4. После успешного завершения скачайте artifact **Cicada-RU-Windows-x64**.

Результат — самоустанавливающийся EXE для Windows x64.

## Локализация

- `overlay/ru_windows.json` — русские строки интерфейса.
- `overlay/apply_ru.py` — создаёт русские таблицы локализации, добавляет «Русский» в настройки, включает культуру `ru-RU`, задаёт отдельный канал обновлений и версию RU-сборки.
- Строки, которые пока не переведены, остаются на английском.

## Обновления

Приложение проверяет обновления в Releases этого репозитория, а не в оригинальном Cicada. Публиковать новые версии Cicada RU можно отдельными релизами.

## Важно

Сборка не подписана сертификатом издателя Windows. При первом запуске Windows SmartScreen может показать предупреждение. Используйте сборки из этого репозитория и проверяйте исходный код.
